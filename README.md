# 60921OAM_2-course

# Автор проекта: Оздамиров Адам 609-21
# Наименование проекта - Сайт для управления расходами и доходами. EasyMoney - Сайт для управления доходами и расходами
Веб-приложение позволяет зарегистрированному пользователю учитывать и анализировать личные расходы и доходы(возможно также семейные), группировать их по категориям("транспорт", "развлечения", "Продукты", "Зарплата", "Питание"). Возможно добавление своих категорий("Фиксированные затраты", "Переменные затраты"). Также будут доступны поиск и фильтрация по расходам, доходам, категориям.
